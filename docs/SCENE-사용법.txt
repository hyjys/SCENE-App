SCENE App v0.3
연극 동아리 SCENE 음향팀용

1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. sceneapp.exe를 실행합니다.
   sceneapp.exe, ffmpeg.exe는 같은 폴더에 둡니다.
   yt_dlp Python 모듈이 내장되어 yt-dlp.exe는 필요하지 않습니다.
   CustomTkinter 화면에 나눔고딕 폰트를 적용합니다. 폰트 설치는 필요 없습니다.
   Windows 표시 언어가 한국어이면 한국어로, 그 외에는 영어로 표시합니다.

[링크에서 MP3 만들기]
번호와 제목, 동영상 링크를 입력하고 다운로드 버튼을 누릅니다.
오디오 전용 형식 중 비트레이트가 가장 높은 형식을 자동으로 고른 뒤
바로 MP3로 변환합니다. 별도의 목록 조회나 형식 선택은 필요 없습니다.

[외부 파일을 MP3로 만들기]
파일 변환 탭에서 음원 파일을 고르고 번호와 제목을 입력한 뒤 변환합니다.
WAV, FLAC, M4A, OGG 등 FFmpeg가 읽을 수 있는 파일을 사용할 수 있습니다.
영상 파일을 고른 경우 첫 번째 오디오 트랙만 사용합니다.
원본 파일은 그대로 두고 새 MP3를 만듭니다.

[파일 이름과 저장 위치]
번호 7 / 제목 오프닝 → bgm7_오프닝.mp3
번호 13 / 제목 암전 → bgm13_암전.mp3
번호 007 / 제목 전환 → bgm007_전환.mp3
번호 7.5 / 제목 전환 → bgm7.5_전환.mp3
번호 007.50 / 제목 전환 → bgm007.50_전환.mp3
bgm 뒤에는 직접 입력한 번호가 들어갑니다.
번호는 소수점 한 개를 사용할 수 있고 숫자는 총 12자리까지 입력할 수 있습니다.
저장할 수 없는 파일명 문자는 밑줄로 바뀝니다.
완성 파일은 실행 파일 옆 Downloads 폴더에 저장됩니다.
같은 파일명이 이미 있으면 (2), (3) 등을 붙여 기존 파일을 보존합니다.
저장 폴더를 열면 완성된 MP3를 확인할 수 있습니다.

[변환 품질]
libmp3lame / VBR 2 설정입니다.
MP3 변환은 항상 적용됩니다. MP3로 바꿔도 원본보다 음질이 좋아지지는 않습니다.

[오류와 취소]
작업 로그에서 선택된 형식, 다운로드와 변환 진행 상황을 확인할 수 있습니다.
취소 버튼으로 중단할 수 있으며 미완성 파일의 위치는 로그에 표시됩니다.
오디오 전용 형식이 없는 링크는 오류로 안내합니다.
일부 사이트의 로그인·접근 제한 때문에 다운로드가 실패할 수 있습니다.
링크 다운로드에는 인터넷이 필요하고 파일 변환은 오프라인으로 가능합니다.
Python이나 JavaScript 런타임을 따로 설치할 필요는 없습니다.

[블랙스크린 ON/OFF]
프로젝터나 보조 모니터를 연결하고 Win+P에서 확장을 선택합니다.
SCENE App의 블랙스크린 ON 버튼을 누르면 보조 화면 한 대가 검정으로 덮입니다.
블랙스크린 OFF 버튼으로 해제하며, 다운로드·변환 중에도 조작할 수 있습니다.
주 모니터는 덮지 않습니다. 보조 화면이 없으면 확장 설정 안내를 표시합니다.
비주 모니터 중 Windows 내부 장치명 DISPLAY2를 우선 사용합니다.
내부 장치명은 Windows 설정 화면의 식별 번호와 다를 수 있습니다.

검은 창은 RGB 0,0,0이며 테두리·글자·버튼이 없습니다.
음향 프로그램의 키보드 포커스를 빼앗지 않고 검은 화면에서 커서를 숨깁니다.
마우스를 검은 보조 화면 쪽으로 옮기고 Alt+F4를 눌렀다 놓으면
블랙스크린만 해제됩니다. Esc·클릭·더블클릭으로는 해제하지 않습니다.
연결이 끊기면 창을 숨기고 재연결을 기다리며 앱 종료 시 함께 정리합니다.
활성화 중에는 Windows에 화면·시스템 절전 방지를 요청합니다.

SCENE BlackScreen 1.0의 화면 덮기 동작을 통합한 기능입니다.
Epson PJ 제어·DDC/CI 밝기 조절은 포함하지 않습니다.
디스플레이 전원·오디오 출력장치·볼륨을 변경하지 않습니다.
검정 화면만으로 프로젝터의 빛이 완전히 차단되지는 않을 수 있습니다.
