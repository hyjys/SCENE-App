SCENE App v0.5
11월 공연 종료 기념 업데이트 · 12월 공연 준비와 무대 운영

[설치와 실행]
설치형: sceneapp-0.5-windows-x64-setup.exe를 실행합니다.
포터블: scene-app.zip 전체를 쓰기 가능한 폴더에 풀고 sceneapp.exe를 실행합니다.
sceneapp.exe와 ffmpeg.exe는 같은 폴더에 둡니다.
Python, Deno, 나눔고딕과 문서·웹 라이브러리는 배포본에 포함됩니다.
웹 패널에는 Microsoft Edge WebView2 Runtime이 필요합니다.
설치되어 있지 않으면 앱의 안내에 따라 아래 Microsoft 공식 페이지에서 설치합니다.
https://developer.microsoft.com/microsoft-edge/webview2/#download-section
상단에서 준비 모드 또는 무대 모드를 선택합니다. 무대는 최대화 창으로 열립니다.
준비 모드로 돌아오면 음원과 프로젝터 영상이 정지합니다.

[준비 모드: 음원과 영상]
1. 번호와 제목을 입력합니다.
2. 링크 다운로드 또는 외부 파일 변환을 선택합니다.
3. 주소를 붙여넣거나 파일을 선택합니다.
4. 기본은 MP3입니다. 영상이 필요하면 영상 토글을 켭니다.
5. 실행 버튼을 누르고 Downloads 폴더에서 결과를 확인합니다.

번호 7 / 제목 오프닝 → bgm7_오프닝.mp3
번호 7.5 / 제목 전환 → bgm7.5_전환.mp3
영상 토글 ON → 같은 번호와 제목의 .mp4
007.50처럼 입력한 번호 표기를 유지합니다. 숫자는 소수점 제외 총 12자리까지입니다.
같은 파일명에는 (2), (3) 등을 붙이며 기존 파일과 외부 원본을 보존합니다.
MP3: 오디오 전용 최고 비트레이트 선택, libmp3lame VBR 2.
영상 기본: libx264 H.264 / veryslow / CRF 20 + MP3 VBR 2.
앱 설정에서 인코더·프리셋을 바꿀 수 있으며 Intel Quick Sync와 NVIDIA NVENC를 지원합니다.
GPU 인코딩에는 지원 장치와 드라이버가 필요합니다.
로그·취소를 제공하며 네트워크 요청 중에는 취소 반영에 시간이 걸릴 수 있습니다.
일부 사이트의 로그인·접근 제한으로 다운로드가 실패할 수 있습니다.
파일 변환은 오프라인으로 가능합니다. 프로젝터·암전 제어는 무대 모드에 있습니다.

[무대 모드: 왼쪽 음향 제어반]
폴더 선택으로 준비한 음원·영상이 있는 폴더를 열면 하위 폴더도 모두 불러옵니다.
선택한 폴더에 바로 있는 파일을 먼저 표시합니다.
오프닝·커튼콜 등 하위 폴더는 맨 아래에 알파벳순·가나다순으로 묶어 표시합니다.
폴더 이름 옆 삼각형(▶/▼)을 누르면 펼치거나 접습니다. 중첩 폴더도 지원합니다.
각 폴더의 파일은 bgm1, bgm2, bgm2.5, bgm10처럼 번호를 숫자 순으로 정렬합니다.
영상도 BGM 번호를 이어 사용하며 목록에서 프로젝터로 재생할 수 있습니다.
각 행과 하단에서 재생·일시정지·정지·페이드인·페이드아웃을 조작합니다.
탐색 바로 재생 위치를 이동하고 볼륨을 조절합니다. Windows 전체 볼륨은 바꾸지 않습니다.
페이드인 기본: 3초, 0% → 100%. 페이드아웃 기본: 3초, 100% → 0%.
앱 설정에서 전역 기본 볼륨과 페이드 시간·시작·종료 비율을 정합니다.
파일 우클릭 또는 음원 설정에서 그 파일만 다른 값을 지정합니다.
전역 기본값 사용으로 개별 설정을 해제합니다.
개별 설정은 음원 폴더의 .scene-audio.json에 보관합니다.
폴더 쓰기 권한이 필요하며 공연 자료를 옮길 때 함께 옮깁니다.

[무대 모드: 오른쪽 대본]
대본 열기로 TXT, DOCX, PDF를 엽니다.
DOCX는 문단·표와 일부 글자 서식을 가져오며 Word 페이지 배치는 재현하지 않습니다.
PDF는 페이지 비율을 유지해 표시하고 이전·다음 쪽으로 이동합니다.
A−/A+로 글자 크기 또는 PDF 확대율을 조절합니다.
글자를 선택하거나 PDF에서 사각형을 드래그한 뒤 형광펜·글자색을 적용합니다.
PDF 색 변경은 선택 영역의 화면 표시 효과입니다.
선택 표시 지우기로 해당 범위의 표시·큐를 제거합니다.

[오디오 하이라이팅]
1. 대본 글자 또는 PDF 영역을 선택합니다.
2. ♪ 오디오 큐 추가를 누릅니다. PDF는 현재 쪽에도 추가할 수 있습니다.
3. BGM 번호(예: 2.5) 또는 파일명과 동작을 고릅니다.
4. 볼륨 변경은 %, 재생 위치 이동은 초 단위 숫자를 입력합니다.
5. 하단 큐 목록의 위치로 대사를 확인하고 GO로 실행합니다.
지원 동작: 재생, 일시정지, 정지, 페이드인, 페이드아웃, 볼륨, 재생 위치.
대상을 비우면 현재 음원에 적용합니다. 열기·스크롤·큐 선택만으로 소리가 나지는 않습니다.
표시·큐는 대본.docx.scene.json처럼 원본 옆 파일에 자동 저장합니다.
TXT, DOCX, PDF 원본은 수정하지 않습니다. 폴더 쓰기 권한이 필요합니다.
원본과 표시 파일을 함께 보관하세요. 원본이 바뀌면 이전 표시를 자동 적용하지 않습니다.
이후 새 표시 저장 전에 이전 표시 파일을 백업합니다.

[무대 모드 우하단 프로젝터]
프로젝터나 보조 모니터를 연결하고 Win+P에서 확장을 선택합니다.
암전 ON/OFF, 영상 열기, 일시정지, 재개, 정지를 사용할 수 있습니다.
목록의 영상도 같은 개별 볼륨·페이드 설정을 사용합니다.
영상 페이드는 화면 밝기·음량에 적용합니다. 암전 ON은 영상을 정지합니다.
주 모니터는 덮지 않고 비주 모니터 중 내부 장치명 DISPLAY2를 우선합니다.
내부 이름은 Windows 설정의 식별 번호와 다를 수 있습니다.
검은 화면 위로 마우스를 옮긴 뒤 Alt+F4를 눌렀다 놓으면 블랙스크린만 해제됩니다.
블랙스크린은 Esc·클릭으로 해제하지 않습니다.
연결이 끊기면 검은 창을 숨기고 재연결을 기다립니다.
영상 창은 Esc/Alt+F4로 닫을 수 있고 화면 연결이 끊기면 정지합니다.
앱 종료 시 출력도 정리합니다. 검정 화면은 광원을 물리적으로 차단하지 않습니다.
Epson PJ·DDC/CI 제어는 포함하지 않습니다.
실제 공연 장비에서 영상·음향 동기와 연결 변경을 리허설로 확인하세요.

[로컬과 웹 / Google]
앱 설정에서 음향과 대본의 소스를 각각 local 또는 web으로 지정합니다.
한쪽만 웹으로 사용할 수 있으며 패널에서도 전환할 수 있습니다.
웹 주소를 입력하고 열기를 누르면 tkwebview 0.3.0 / Microsoft Edge WebView2로 표시합니다.
tkwebview는 tkwebview2의 후속 프로젝트로 Chromium의 JavaScript·DOM 엔진을 사용합니다.
Google 검색·Docs·Drive 등의 웹 페이지를 표시하며 별도 Python JavaScript 엔진은 필요 없습니다.
Google에서 내장 브라우저 로그인을 제한하면 브라우저에서 열기를 사용합니다.
WebView2 Runtime이 없으면 설치 안내를 표시하며 로컬 기능은 계속 사용할 수 있습니다.
로그인 없이 읽을 수 있는 Docs 공유 링크로 Google 대본 가져오기를 사용할 수 있습니다.
텍스트를 로컬 뷰어로 가져와 표시·큐를 추가하며 Google 원본에는 쓰지 않습니다.
로그인 전용 문서는 브라우저에서 내려받아 로컬 파일로 여세요.
Drive 음원은 내려받아 음원 폴더에서 선택하면 로컬 제어반·대본 큐로 운영할 수 있습니다.
웹 화면의 재생 버튼과 로컬 음향 큐는 자동 연동하지 않습니다.
전역 설정: %APPDATA%\SCENE App\settings.json
가져온 Google 대본: 같은 폴더 아래 Google 대본

[업데이트]
준비 모드 시작 시 최신 정식 릴리스를 확인합니다. 앱 설정에서 자동 확인을 끌 수 있습니다.
업데이트 확인 → 업데이트 다운로드 → 앱 종료 후 설치 순서입니다.
무대 모드에서는 설치하지 않습니다. 확인만으로 설치하지 않으며 다운로드는 취소할 수 있습니다.
설치 파일은 hyjys/SCENE-App GitHub Releases에서 가져옵니다.
sceneapp-{version}-windows-x64.exe 또는 -windows-x64-setup.exe를 인식합니다.
릴리스에 설치 파일이 아직 없으면 안내 후 나중에 다시 확인합니다.
